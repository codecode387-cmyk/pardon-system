# Verse Screen

Listens to the preacher, spots Bible references, and shows the verse on a second screen.

## Run locally
    npm i -g vercel
    vercel dev
Open http://localhost:3000 in Chrome. Click "Open display window", drag that window to the projector, press F11.

## Deploy
1. Push this folder to a GitHub repo.
2. On vercel.com choose "Add New > Project", import the repo, click Deploy (no settings needed).
3. Open your Vercel URL in Chrome on the church computer.

## How to use
- Keep "Show detected verses automatically" OFF at first. Click "Show on screen" to approve each verse.
- Plug the preacher's mic (or a sound desk feed) into the computer for best accuracy.
- Display and operator windows must be in the same browser on the same computer.
